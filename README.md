# Data Cleaning Using Python

## Project Overview
This project demonstrates how to clean and preprocess raw data using Python and the Pandas library. The goal is to prepare the dataset for analysis by handling missing values, duplicate records, incorrect data types, and formatting issues.

## Features
- Load CSV dataset
- Remove duplicate records
- Handle missing values
- Convert date columns to datetime format
- Standardize text values
- Save the cleaned dataset

## Technologies Used
- Python 3
- Pandas
- VS Code

## Project Structure

Data_Cleaning_Using_Python/
│── data.py
│── cleaned_data.csv
│── README.md


## How to Run
1. Clone the repository.
2. Install Pandas:
   
   pip install pandas
   
3. Run the program:
   
   python data.py
   

## Output
The program generates a cleaned dataset named:

cleaned_data.csv
